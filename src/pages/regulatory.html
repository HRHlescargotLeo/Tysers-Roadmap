Regulatory status

How each Tysers entity is authorised and regulated. Tysers is a member of the AUB Group.

What we're proposing

One row per entity, each with the same fields: name, regulator, reference number linked to the regulator's register, and registered office. Entities are linked to their office records, so the office page shows the same regulator.

Why

The live page quotes the Belgium UK Branch's Firm Reference Number (973102) but not the FRN for Tysers Insurance Brokers Limited, the main UK firm. A heading reads "Tysers New Zealand H2". Bank account details are published inline, which we'd suggest checking is still intended.
