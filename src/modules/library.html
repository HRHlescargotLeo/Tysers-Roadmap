Prototype reference

Module library

Every reusable block in the prototype, shown once. In Umbraco each is a Block List or Block Grid element that editors add to pages; the name in brackets is the block's working name.

What we're proposing

A small, deliberate set of blocks. Most pages on the new site are assembled from these fifteen, which keeps the editing experience simple and the pages consistent.

Why

Several blocks are linked to content trees (People, Specialties, Offices, Insights, Claims routes) rather than holding their own copy, which is what stops the same phone number appearing in three places with three different values.
